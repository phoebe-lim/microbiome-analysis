Scripts written for an MSc Genomic Medicine project titled "Microbiome and clinical associations with the *MUC5B* genotype in idiopathic pulmonary fibrosis (IPF) patients".<br><br>
Scripts were written for the following purposes:<br>
**0-merge-sheets**: Metadata curation<br>
**1-QC-preprocess** and **2-batch-correction**: Quality control and preprocessing of 16S rRNA sequencing data<br>
**3-micro-analysis-MUC5B**: Microbiome and survival analyses
